# Personal CRM Ver.3.3 — 会計ソフト選択に依存しないデータ出力

## 追加
- 設定 → データ管理 → 会計ソフト連携用 共通データ
- 当年／前年のイベントCSV（請求書発行・入金確認）。元データは読み取りのみ。既存DB/認証/請求書に変更なし。
- 請求ID＋イベント種別による重複識別、請求日・入金日未設定のチェック行。

## 重要な制約
- **freee/マネーフォワードの直接インポートファイルではありません**。各社の会計処理形式は異なります。
- 請求・入金イベントと仕訳は同義ではありません。前受金や期跨ぎ・消費税・所得区分は会計ソフトで判断してください。
- 入金確認イベントは、銀行振込明細を会計側で取り込んだ場合に**二重計上しない**よう照合が必要です。
- 現CRMは入金日が1件だけのため分割入金や複数銀行口座は未表現。直接API連携は未実装。
- 年度判定はイベント日を基準にしています。日付未入力の請求はレビュー行として年度に関係なく出力されます。
- ファイルは取引先情報を含むため厳重に保管してください。

## 適用手順
1. ZIPの `personal-crm-v3.3/` の中身をGitHubリポジトリのルートへコピーします。
2. Vercelの自動ビルドを確認します。
3. CRMの「設定」→「データ管理」から今年の会計連携CSVをダウンロードし、Excelで確認します。
4. Supabase migration / Google Cloud / Vercel環境変数の追加は不要です。

- API連携はユーザーの明示操作・重複検査・監査ログ付きで提供
