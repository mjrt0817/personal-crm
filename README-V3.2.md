# Personal CRM Ver.3.2 — 見積期限管理・コピー

Ver.3.1を基にした更新版です。DBマイグレーションの追加はありません。

## 主な変更

1. 見積の `valid_until` は当日末まで有効（日本時間）。翌日以降、下書き・送付済は画面上で「期限切れ」になります。採用済み／不採用は自動変更しません。
2. 期限切れ見積の「採用・案件化」を画面から非表示にし、サーバー側でも採用・復活を阻止します。期限切れの送付済見積の内容を変更して再利用せず、コピーして改めて発行してください。
3. 見積一覧／詳細に「コピー」ボタンを追加しました。元の見積は変更せず、新しい番号、作成当日の日付、設定の既定有効日数による期限で新たな下書きを作ります。明細・宛名・条件などを引き継ぎ、採用日・発行時スナップショットは引き継ぎません。コピー直後は編集画面に移動します。
4. 見積一覧に「期限切れ」フィルターを追加しました。

## 更新

GitHubリポジトリ直下にZIP内の `personal-crm-v3.2` フォルダの**中身**を反映し、Vercelのビルドを確認してください。

- Google Cloud：変更なし
- Vercel環境変数：変更なし

## 注意

- 今回の「期限切れ」は読込時に日本時間で計算する**有効ステータス**です。DBの`status`列を自動的に書き換えるCronではありません。従来のデータを保持したまま、画面と採用操作で失効を強制します。
- `valid_until` が未設定の見積は期限切れ判定をしません。
- 既に採用済みの見積は、有効期限を過ぎても履歴を維持します。
- クライアントでのUIテストと完全なVercel本番ビルドは、配備先で最終確認してください。今回変更した4ファイルのTypeScript構文解析は成功しています。
- コピー処理は既存の見積番号採番に依存します。並列大量コピーなどの完全なトランザクション保証は今後の改善課題です。

## 動作テスト

1. 期限が昨日の送付済見積が「期限切れ」と表示されること
2. 「採用・案件化」が表示されないこと
3. 「コピー」を押して編集画面に移動し、新規番号・当日期限が付いていること
4. 明細・税率・宛名が引き継がれていること
5. コピー元のステータスと履歴が変化しないこと
6. 採用済み見積が、期限を過ぎても「採用」のまま残ること

## 確定申告

現行CRMは請求／入金／見積／契約管理であり、総勘定元帳、複式仕訳、固定資産台帳、現預金・銀行照合、経費証憑、消費税区分、年末整理・決算などの申告に必要な機能は未実装です。そのため申告書や青色申告決算書の正式作成機能は今回追加していません。

推奨はCRMを営業・請求のマスターとして、月次に請求・入金データをエクスポートし、マネーフォワード クラウド確定申告等へ照合して登録する方式です。個人事業の青色申告・インボイス対応を行う場合、会計・申告は専用ソフトで処理してください。
