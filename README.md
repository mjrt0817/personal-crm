# Personal CRM Ver.2.7

Ver.2.7では、Ver.2.6の請求・入金管理をベースに、日常入力時の使い勝手とデータ整合性を優先して改善しました。

主な変更は次の3点です。

1. 案件の主担当者を、選択した取引先の担当者だけに制限
2. タスク編集・活動・関連URL・予定などの入力フォームの余白を統一
3. 請求・入金画面の絞り込みと案件別請求状況を見やすく改善

## 1. 案件登録・編集時の担当者制限

案件登録／編集画面では、先に取引先を選択すると、その取引先に登録されている担当者だけが「主担当者」の候補に表示されます。

取引先を変更した場合、以前の担当者が新しい取引先に所属していなければ自動的に未設定へ戻します。

さらに、画面上の制御だけではなく、以下の2段階で不整合を防ぎます。

- Server Actionで担当者と取引先の一致を検証
- PostgreSQL側にも複合外部キーを追加

そのため、将来別の入力経路を追加しても、異なる取引先の担当者を案件へ誤登録しにくい構造です。

## 2. 入力フォームの余白調整

これまで、タスク編集など一部画面では入力欄がカード枠のすぐ内側から始まっていました。

Ver.2.7では以下の画面を中心に、カード内側へ統一した余白を追加しています。

- タスク編集
- 担当者編集
- Gmailからのタスク作成
- 関連URL追加・編集
- 活動記録追加・編集
- 案件内予定追加
- 予定編集

PCでは20px、スマートフォンでは16pxを基本余白としています。

## 3. 請求・入金画面の強化

請求・入金画面のフィルターを増やしました。

- 未請求・未入金
- 請求対象未登録
- 今月請求予定
- 支払期限7日以内
- 期限超過
- 未請求（予定登録済）
- 請求済
- 入金済
- すべて

「請求対象未登録」では、実施済み・受注済み売上のうち、まだ請求予定レコードを作成していない案件だけを確認できます。

請求一覧には「請求予定日 / 請求日」を追加し、メモがある場合は短いプレビューも表示します。

## 4. 案件別の請求状況

案件ごとの請求画面は、次の4指標へ整理しました。

- 案件予定売上
- 請求前
- 請求済累計
- 入金済

「請求済累計」には、未入金額や期限超過額も補足表示します。

案件詳細の簡易請求カードも、

- 請求前
- 請求済
- 未入金
- 入金済

の4つに揃えました。

# 更新手順

## STEP 1: Supabase migration

GitHub更新より先に、Supabaseの **SQL Editor** で次を実行してください。

`supabase/migrations/012_project_contact_company_guard.sql`

このSQLは、案件の主担当者と取引先の整合性をDB側でも保証します。

既存データに「案件の取引先と異なる担当者」が設定されていた場合、その案件の主担当者だけを安全のため未設定へ戻します。案件・取引先・担当者自体は削除しません。

## STEP 2: GitHubへ上書き

`personal-crm-v2.7` フォルダの **中身** を、現在のGitHubリポジトリ直下へ上書きしてください。

今回も新規ファイル・新規ルートを含め、ZIPには全ソースを収録しています。

## STEP 3: Vercel

mainへ反映すると自動デプロイされます。

今回は以下の変更はありません。

- Google Cloud設定：変更なし
- OAuth Scope：変更なし
- Vercel環境変数：追加なし

# 動作確認

## 担当者制限

1. 案件登録を開く
2. 取引先Aを選択
3. 主担当者に取引先Aの担当者だけ表示されることを確認
4. 取引先Bへ変更
5. 取引先Aの担当者が候補から消えることを確認

## 余白

タスク編集画面を開き、カードの枠と「タスク名」等の入力欄の間に十分な余白があることを確認してください。

## 請求・入金

`請求・入金` 画面で、

- 請求対象未登録
- 今月請求予定
- 期限7日以内

のフィルターが機能することを確認してください。
