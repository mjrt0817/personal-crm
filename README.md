# Personal CRM Ver.3.1

Ver.3.0.5をベースに、継続契約管理と複数契約まとめ請求を追加した版です。

## Ver.3.1 主な追加

### 契約管理
- 1取引先に複数契約を登録可能
- 月契約 / 年間契約
- 前払い（既定） / 後払い
- 契約開始日 / 終了日
- 自動更新フラグ
- 次回サービス期間開始日
- 次回請求予定日
- 契約ごとの金額・税率
- 必要に応じて案件へ紐付け

### 契約請求
- 同じ取引先の複数契約を1枚の請求予定へまとめる
- 契約ごとに請求書の明細行を作成
- 明細に対象サービス期間を表示
- 前払い契約ではサービス期間開始日を支払期限の初期値に設定
- 月契約と年間契約を同じ請求書へ混在可能
- 請求予定作成後、各契約の次回請求・次回期間を1周期進める
- 未発行請求の削除/取消時は、安全に戻せる場合のみ契約サイクルを巻き戻す

### 請求書
- 既存の1明細請求書に加え、複数契約明細を表示
- 明細ごとの税率から内税を集計
- 発行済み請求書は従来どおりスナップショット固定

### 取引先画面
- 契約一覧を追加
- 取引先から直接「＋契約」を登録可能

### バックアップ
- contracts
- contract_invoice_lines
をJSONバックアップ対象へ追加
- 契約CSV出力を追加

## 更新手順

### 1. Supabase SQL Editor

`supabase/migrations/017_contract_management.sql` を全文実行してください。

このmigrationでは以下を行います。
- `contracts` テーブル追加
- `contract_invoice_lines` テーブル追加
- `project_invoices.project_id` をnullable化
- `project_invoices.source_type` 追加
- RLS設定
- 発行済み契約請求明細の変更防止

既存の案件・請求書は削除しません。

### 2. GitHub

`personal-crm-v3.1` フォルダの中身を、現在のリポジトリ直下へ上書きしてください。

新規ルートがありますので、ファイル単体ではなくフォルダ構造ごとの反映を推奨します。

新規追加の主な場所：

```
app/(app)/contracts/
components/ContractForm.tsx
components/ContractInvoiceForm.tsx
components/ContractInvoiceEditForm.tsx
supabase/migrations/017_contract_management.sql
```

### 3. Vercel

GitHub反映後の自動デプロイのみです。
追加の環境変数はありません。

## 利用例

同じ取引先に以下の契約がある場合：

- コーポレートサイト保守：月額 10,000円
- 採用サイト保守：月額 8,000円
- 年間ドメイン・運用管理：年額 24,000円

請求時に3契約を選択すると、1枚の請求書に3明細として表示できます。

```
コーポレートサイト保守（2026/11/01〜2026/11/30）  10,000円
採用サイト保守（2026/11/01〜2026/11/30）          8,000円
年間ドメイン・運用管理（2026/11/01〜2027/10/31） 24,000円
```

## 確認ポイント

1. 契約管理 → ＋契約
2. 同じ取引先へ月契約を2件以上登録
3. 次回請求予定日を当日以前にする
4. 契約管理または請求・入金から「まとめて請求」
5. 2契約以上にチェック
6. 請求予定を作成
7. 請求書を開き、複数明細が1枚に表示されることを確認
8. 「請求済」にして発行者・請求先・明細が固定されることを確認
