# Personal CRM Ver.2.4

Ver.2.4は、画面の余白調整とSFAとしての売上・見込管理を強化した更新です。
AI参謀は機能を追加せず、忘れないようサイドメニューへ再表示しています。

## 主な変更

### 1. AI参謀をサイドメニューへ再表示
- `🤖 AI参謀` をサイドメニューへ戻しました。
- AI機能そのものの追加開発は今回行っていません。
- OpenAI APIを設定していない場合でも、その他のCRM機能には影響しません。

### 2. カード内の余白を調整
ダッシュボードの「最近更新されたDriveファイル」など、枠線に対して内容が近すぎた箇所を調整しました。

特に `compact-list` の左右余白を復活させ、PC・スマートフォンの双方でカード内の情報が枠へ張り付かないようにしています。

### 3. 売上・見込パイプライン
サイドメニューに `📊 売上・見込` を追加しました。

表示内容：
- 商談中案件数
- 未受注案件の見込総額
- 加重見込金額
- 今月の受注額
- 累計受注額
- ステータス別パイプライン
- 今月から6か月の月別見込
- 商談案件一覧

### 4. 受注確度
案件に以下を追加しました。

- 受注確度（0～100%）
- 受注見込日

受注確度が未設定の場合、パイプラインではステータスごとの標準確度を使用します。

標準確度：
- 相談 10%
- ヒアリング 20%
- 提案準備 35%
- 提案済 50%
- 検討中 70%
- 保留 25%

受注・対応中・完了は受注済みとして扱うため、未受注パイプラインからは除外します。

### 5. 加重見込
以下で算出します。

`見込金額 × 受注確度`

例：
- 見込金額 200,000円
- 受注確度 60%
- 加重見込 120,000円

単純な見込総額だけではなく、現実的な売上予測を見るための参考値として使います。

### 6. ホームにも売上・見込を表示
ダッシュボードに以下の簡易表示を追加しました。

- 商談中件数
- 見込総額
- 加重見込
- 今月受注

詳細は `売上・見込` 画面へ移動して確認できます。

## 更新手順

### 重要：先にSupabase migrationを実行してください

Supabase > SQL Editor > New query で以下を実行します。

`supabase/migrations/009_sales_pipeline.sql`

このmigrationは既存データを削除しません。
`projects` テーブルへ以下を追加します。

- `win_probability`
- `expected_close_date`

### その後GitHubへ更新

1. `personal-crm-v2.4` フォルダの中身をGitHubリポジトリ直下へ上書き
2. mainへCommit / Push
3. Vercelの自動デプロイ完了を確認

## 今回変更不要なもの

- Google Cloud：変更なし
- Google OAuth Scope：変更なし
- Vercel Environment Variables：変更なし

## 動作確認

1. 案件を1件編集
2. 見込金額を入力
3. 受注確度を入力
4. 受注見込日を入力
5. `売上・見込` 画面を開く
6. ステータス別・月別・加重見込へ反映されることを確認
7. ホームの「最近更新されたDriveファイル」で左右の余白が改善されていることを確認

## 補足

既存案件では受注確度・受注見込日は空欄のままです。
受注確度が空欄でもステータス標準値で加重見込を計算しますが、月別予測には受注見込日の登録が必要です。
