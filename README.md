# Personal CRM Ver.2.9

Ver.2.9では、**見積書作成 → 採用 → 案件への反映 → 請求への引継ぎ**を追加しました。

## 主な追加内容

### 1. 見積管理
サイドメニューに `🧾 見積` を追加しました。

見積ごとに以下を管理できます。

- 見積番号（自動採番）
- 取引先・担当者
- 既存案件への紐付け
- 下書き / 送付済 / 採用 / 不採用 / 期限切れ
- 見積日・有効期限・採用日
- 複数明細
- 数量・単位・単価
- 明細ごとの税率（0% / 8% / 10%）
- 見積条件
- 社内メモ

### 2. DXコンシェルジュ等の「単価 × 回数」に対応
例えば、

- 品目：DXコンシェルジュ支援
- 数量：3
- 単位：回
- 単価：41,000円

のように登録できます。

見積採用時、1明細かつ数量が2以上の場合は、案件側にも **単価 × 回数方式**として引き継ぎます。

### 3. 見積から案件へ引継ぎ
見積詳細画面から、

- 案件未作成 → `採用・案件化`
- 既存案件あり → `採用・案件へ反映`

を実行できます。

採用後に見積内容を変更した場合は `案件へ再反映` も可能です。

### 4. 見積から請求へ引継ぎ
採用済みかつ案件連携済みの見積では、

`見積総額を一括請求予定へ`

から請求予定を作成できます。

※ DXコンシェルジュのように1回ごとに請求する場合は、従来どおり案件の「＋1 実施」→請求対象から回ごとに請求してください。

### 5. 見積書の印刷 / PDF保存
見積詳細の `見積書 / PDF` からA4見積書を表示できます。

ブラウザの `印刷 / PDF保存` を使用します。

### 6. 帳票設定
`設定 → 請求書・見積書設定` に次を追加しました。

- 見積番号の接頭辞（既定：EST）
- 次回採番番号
- 既定の有効日数（既定：30日）
- 見積書の既定条件・注記

発行者名・住所・連絡先は請求書と共通です。

### 7. 案件詳細
案件詳細に、紐付いている見積の一覧を追加しました。
案件から新しい見積を作る場合は、案件・取引先が最初から選択された状態で開きます。

### 8. バックアップ
全データJSONバックアップに、

- estimates
- estimate_items

を追加しました。

設定画面から見積CSVも出力できます。

# 動作確認

最初は次の流れがおすすめです。

1. `見積 → ＋ 見積作成`
2. 取引先・担当者を選択
3. `DXコンシェルジュ支援 / 3回 / 41,000円` などを入力
4. 保存
5. `見積書 / PDF` を確認
6. `採用・案件化` または `採用・案件へ反映`
7. 案件側の単価・予定回数を確認
8. 必要に応じて `見積総額を一括請求予定へ`

## 金額の考え方

見積明細の単価は **税抜単価** として計算し、見積書上で税額を加算します。
41,000円を最終的な税込金額として扱いたい場合は、その明細の税率を `0%` にするか、税抜単価を調整してください。
