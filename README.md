# Personal CRM Ver.2.5

Ver.2.5は、Ver.2.4の売上・見込画面で「既存案件に金額を入れても反映されないように見える」問題を修正し、DXコンシェルジュのような **単価 × 実施回数** の案件を管理できるようにした更新です。

## 1. 金額が反映されない問題の修正

Ver.2.4では、`対応中 / 受注 / 完了` の案件を「受注済み」として商談パイプラインから除外していました。
そのため、対応中の既存案件へ見込金額だけを入力しても「見込総額」には出ず、受注金額が未入力だと受注側にも金額が見えにくい状態でした。

Ver.2.5では以下を修正しています。

- Supabaseの `numeric` 値をアプリ側で必ず数値へ正規化
- 対応中・受注・完了案件は「受注・進行中案件」として別一覧に表示
- 固定金額案件で受注金額が未入力の場合、受注済みステータスでは見込金額を予定額として補完表示
- ホーム画面にも「受注・進行中」の総額を表示

## 2. 「単価 × 回数・数量」方式を追加

案件編集の「金額・メモ」に `金額管理方式` を追加しました。

### 固定金額
従来どおり、
- 見込金額
- 受注金額

で管理します。

### 単価 × 回数・数量
以下を登録します。

- 単位（例：回、時間、月）
- 単価
- 予定回数・数量
- 実施済み回数・数量

自動計算：

- 予定売上 = 単価 × 予定回数
- 実施済み売上 = 単価 × 実施済み回数
- 残り見込 = 予定売上 - 実施済み売上

## 3. DXコンシェルジュ案件の例

例えば全3回・1回41,000円の場合：

- 金額管理方式：単価 × 回数・数量
- 単位：回
- 単価：41,000円
- 予定回数：3
- 実施済み：0

予定売上は自動で `123,000円` になります。

### 2回で終了した場合
案件編集で予定回数を `2` に変更します。

→ 最終予定額 `82,000円`

### 5回へ増えた場合
予定回数を `5` に変更します。

→ 予定額 `205,000円`

## 4. 案件詳細から実施回数を更新

単価 × 回数の案件では、案件詳細の概要に

`実施回数 2 / 3 回`

のように表示します。

- `−1`
- `＋1 実施`

から回数をすぐ変更できます。

予定回数を超えて `＋1` した場合は、予定回数も自動で実施回数まで増やします。
例えば3回予定から4回目を実施した場合、4 / 4回になります。

2回で終了するなど予定回数を減らす場合は、案件編集画面から予定回数を変更してください。

## 5. 売上・見込画面

### 商談中
従来のSFAパイプラインです。

- 見込総額
- 受注確度
- 加重見込
- 受注見込日

### 受注・進行中案件
新しく以下を表示します。

- 案件
- 状態
- 金額方式
- 予定・受注額
- 実施済み
- 残り

これによりDXコンシェルジュのような「回数で最終金額が変わる案件」も、商談後まで追跡できます。

# 更新手順

## 重要：先にSupabase migrationを実行

Supabase > SQL Editor > New query で、次を全文実行してください。

`supabase/migrations/010_project_unit_pricing.sql`

既存案件は削除・変更されません。既存案件は自動的に `固定金額` 扱いになります。

追加される項目：

- `pricing_model`
- `unit_label`
- `unit_price`
- `planned_units`
- `completed_units`

## その後GitHubへ更新

1. `personal-crm-v2.5` フォルダの中身をGitHubリポジトリ直下へ上書き
2. mainへCommit / Push
3. Vercelの自動デプロイ完了を確認

## 今回変更不要

- Google Cloud：変更なし
- Google OAuth Scope：変更なし
- Vercel Environment Variables：変更なし

# 動作確認

### 既存固定金額案件
1. 対応中の既存案件を編集
2. 見込金額または受注金額を入力
3. `売上・見込` を開く
4. 「受注・進行中案件」に金額が表示されることを確認

### DXコンシェルジュ
1. 案件編集
2. 金額管理方式を `単価 × 回数・数量`
3. 単価 `41000`
4. 予定回数 `3`
5. 保存
6. 案件詳細で `123,000円` と表示されることを確認
7. `＋1 実施` を押し、実施済み `41,000円` になることを確認
