# Personal CRM Ver.2.6

Ver.2.6では、案件の「売上見込・実施済み」から一段進めて、**請求予定 → 請求済 → 入金済**まで管理できるようにしました。

今回の目的は、請求書PDFを作ることではなく、まず「請求漏れ」「未入金」「支払期限超過」をCRM内で見失わないことです。

## 1. 追加した機能

### 請求・入金画面
サイドメニューに `💴 請求・入金` を追加しました。

表示する内容：

- 未請求
- 未入金
- 支払期限超過
- 入金済
- 7日以内に支払期限を迎える請求
- 請求一覧

状態は次の4種類です。

- `未請求（予定）`
- `請求済`
- `入金済`
- `取消`

一覧上から、

- 未請求 → `請求済みにする`
- 請求済 → `入金済みにする`

と進められます。

## 2. 「請求対象」を自動抽出

請求予定をまだ作っていなくても、CRM側の案件情報から請求対象を自動抽出します。

### 単価 × 回数案件
例：DXコンシェルジュ

- 単価：41,000円
- 実施済み：2回
- 請求割当済み：1回

の場合、

`1回 / 41,000円` を新しい請求対象として自動表示します。

案件詳細で `＋1 実施` を押したあと、請求・入金画面を見ると請求対象に出るため、請求漏れを確認できます。

### 固定金額案件
受注・対応中・完了になっている固定金額案件で、受注・予定額に対してまだ請求予定／請求済レコードがない金額を請求対象として表示します。

## 3. 案件ごとの請求管理

案件詳細のタブ内ではなく、案件上部付近に独立した **「請求・入金」カード** を追加しました。

表示内容：

- 未請求
- 未入金
- 期限超過
- 入金済
- 未割当の請求候補

`詳細` を押すと、その案件だけの請求履歴画面へ進みます。

案件別請求画面では、

- 案件売上
- 未請求
- 未入金
- 入金済
- 請求履歴

を確認できます。

## 4. 請求登録

登録項目：

- 請求名
- 状態
- 請求額
- 請求予定日
- 請求日
- 支払期限
- 入金日
- 請求書番号・管理番号
- メモ

単価 × 回数案件の場合は、さらに

- 今回の回数・数量
- 単価

を登録します。

実施済み回数から未請求分を自動計算し、初期値として表示します。

## 5. ダッシュボード・売上画面

### ホーム
「請求・入金」を追加し、

- 未請求
- 未入金
- 期限超過
- 入金済

を確認できます。

### 売上・見込
商談パイプラインとは別に「請求・入金状況」を追加しました。

これにより、

`見込 → 受注 → 実施 → 請求 → 入金`

を一つのCRM上で確認できます。

## 6. バックアップ

以下もVer.2.6で対応しています。

- 全データJSONバックアップに `project_invoices` を追加
- CSV出力に `請求・入金CSV` を追加

Google OAuthのRefresh Token等は、これまで通りバックアップ対象外です。

# 更新手順

## STEP 1: Supabase migration

GitHub更新より先に、Supabaseの **SQL Editor** で次を実行してください。

`supabase/migrations/011_billing_and_payments.sql`

このSQLは `project_invoices` テーブルを追加します。

既存の取引先・案件・タスク・売上データは変更しません。

## STEP 2: GitHubへ上書き

`personal-crm-v2.6` フォルダの **中身** を、現在のGitHubリポジトリ直下へ上書きしてください。

- `app/`
- `components/`
- `lib/`
- `supabase/`
- `package.json`
- `vercel.json`

## STEP 3: Vercel

mainへ反映すると自動デプロイされます。

今回は以下の変更はありません。

- Google Cloud設定：変更なし
- OAuth Scope：変更なし
- Vercel環境変数：追加なし

# 動作確認のおすすめ

DXコンシェルジュ案件で確認する場合：

1. 案件を `単価 × 回数` にする
2. 単価 `41,000円`
3. `＋1 実施` を押す
4. `請求・入金` を開く
5. 「請求対象」に `41,000円` が出ることを確認
6. 「請求予定を作る」
7. `請求済みにする`
8. `入金済みにする`

この流れが通ればVer.2.6の主要機能は正常です。
