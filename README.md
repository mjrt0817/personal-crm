# Personal CRM Ver.2.1

Ver.2.0をベースに「今日・今週の優先アクション」を自動整理するアクションセンターを追加しました。

## Ver.2.1 追加内容

- サイドメニューに **優先アクション** を追加
- `/focus` にアクションセンターを新設
- 「今日優先 / 今週 / 要確認 / すべて」の4区分
- 次の情報を横断して優先順位を自動計算
  - 期限超過・今週期限のタスク
  - 回答待ちフォロー
  - 案件の次回アクション期限
  - 案件納期
  - 今週の予定と準備
  - 14日以上活動がない案件
  - 次回アクション未設定案件
  - Gmail同期済みだが、活動・タスク化していない受信メール
- ホームに「優先アクションを見る」導線を追加
- 各候補には「なぜ候補になったか」を表示

## 優先順位について

AIによる推測ではなく、登録済みデータを使ったルールベースです。

大まかな優先順は以下です。

1. 期限超過タスク
2. 回答待ちフォロー期限到来
3. 案件の次回アクション期限超過
4. 今日〜24時間以内のタスク・次回アクション・予定
5. 直近の未処理Gmail
6. 今週期限・今週予定
7. 次回アクション未設定・14日活動なし

タスク/案件の優先度「高・中・低」もスコアへ加味します。

## 更新手順

今回、Supabase migration・Google Cloud設定・Vercel環境変数の追加はありません。

1. `personal-crm-v2.1` フォルダ内のファイルをGitHubリポジトリ直下へ上書き
2. mainへCommit / Push
3. Vercelの自動デプロイ完了を確認
4. CRMの「優先アクション」を開く

## 動作確認

- 期限超過タスクが「今日優先」に出る
- 3日以上の回答待ちが「今日優先」に出る
- 7日以内の期限・予定が「今週」に出る
- Gmail同期後、活動・タスク化していない受信メールが候補になる
- 進行中で次回アクション未設定の案件が「要確認」に出る
- 各「開く」からタスク編集・案件詳細へ移動できる

## 設計上の意図

この機能は「CRMに情報は入っているが、結局何から手をつければよいか分からない」を避けるためのものです。
将来AIを追加する場合も、まずこのルールベースの候補を土台にすることで、AIが優先順位を説明・提案しやすくなります。
