# Personal CRM Ver.2.0

個人用 SFA / CRM / 案件・タスク管理アプリ。

## Ver.2.0 の追加

- 「待ち」タスクの待機日数を可視化
- フォロー予定日時を任意設定
- フォロー予定未設定の場合、待ち開始から3日でフォロー候補化
- ダッシュボードに「回答待ちフォロー」を表示
- タスク一覧に未完了 / フォロー候補 / 待ち / 期限超過 / 完了 / すべて のフィルター
- 「フォロー済み」で待ち開始をリセット。3日後に再び候補化
- Gmail送信メールから作った回答待ちタスクはメール送信日時を待ち開始として記録

## 更新手順

1. Supabase SQL Editor で `supabase/migrations/007_waiting_task_followup.sql` を実行
2. このフォルダの中身を GitHub リポジトリ直下へ上書き
3. Vercel の自動デプロイ完了を待つ

Google Cloud / OAuth Scope / Vercel環境変数の追加変更はありません。

## 動作確認

- 「待ち」タスクを作る
- タスク編集でフォロー予定を指定できる
- 3日以上待っているタスク、またはフォロー予定日時を過ぎたタスクが「フォロー候補」に出る
- ダッシュボードにも回答待ちフォローが表示される
- 「フォロー済み」を押すと待ち日数が0日に戻る
