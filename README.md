# Personal CRM Ver.2.3

Ver.2.3はAI機能の拡張を一旦止め、日常運用の安全性と管理性を優先した更新です。

## 主な変更

### 1. データバックアップ / CSV出力
設定 > データ管理 から以下をダウンロードできます。

- 全データJSONバックアップ
- 取引先CSV
- 担当者CSV
- 案件CSV
- タスクCSV
- 活動履歴CSV
- スケジュールCSV

JSONバックアップにはCRMの業務データ・Drive/Gmail参照メタデータ・ユーザー設定を含めます。
Google OAuth Refresh Token、Vercel環境変数、Google Client Secretなどの秘密情報は含めません。

安全性を優先し、Ver.2.3ではJSONからの自動復元機能は実装していません。

### 2. アーカイブ管理
設定 > データ管理 > アーカイブを管理 から、アーカイブ済みの案件・取引先を確認して復元できます。

案件を復元した場合、紐づく取引先もアーカイブ済みなら同時に復元します。

### 3. 案件一覧フィルターを実機能化
案件一覧の以下の絞り込みが実際に動作するようになりました。

- 対応中
- 今週期限
- 次回アクションなし
- 活動なし（設定した日数）
- すべて

「活動なし」の日数は設定 > 優先アクションの判定条件で変更できます。

### 4. AI参謀は主導線から一旦外す
AI機能自体のコードは残していますが、サイドメニューからは外しました。
必要になった時点で再度改善します。

## 更新手順

今回はSupabase migration、Google Cloud設定、Vercel環境変数の追加はありません。

1. `personal-crm-v2.3` フォルダの中身をGitHubリポジトリ直下へ上書き
2. mainへCommit / Push
3. Vercelの自動デプロイ完了を確認
4. 設定 > データ管理 でJSONバックアップを一度ダウンロード
5. 案件一覧の各フィルターを確認

## バックアップについて

JSONは主に障害時の確認・将来の復元処理用です。CSVはExcel等で内容を確認・加工する用途です。
バックアップファイルには顧客情報が含まれるため、安全な場所に保管してください。
