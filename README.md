# Personal CRM Ver.2.8

Ver.2.8では、Ver.2.7までの請求・入金管理を実際の請求業務へつなげるため、**請求書発行・印刷/PDF保存**を追加しました。

## 主な追加内容

1. 請求書設定
   - 発行者名 / 屋号
   - 住所・電話・メール
   - 適格請求書発行事業者の登録番号（任意）
   - 振込先
   - 請求書番号の接頭辞
   - 次回採番番号
   - 既定税率
   - 支払・振込に関する注記

2. 請求書番号の自動採番
   - 請求予定を「請求済」にした時、番号が空欄なら自動採番
   - 例：`INV-202609-0001`
   - 手動で番号を指定することも可能

3. 請求書用情報
   - 請求書の明細名
   - 消費税率 0% / 8% / 10%
   - 請求先名・郵便番号・住所
   - 現在の「請求額」は税込総額として扱い、請求書では内消費税を表示

4. 発行時スナップショット
   - 「請求済」にした時点の発行者情報・請求先情報を保存
   - 後から取引先住所や自分の住所を変更しても、発行済み請求書の表示は原則変わりません

5. A4請求書表示
   - 請求・入金一覧、案件別請求履歴に「請求書」ボタンを追加
   - A4の請求書専用画面を表示
   - 「印刷 / PDF保存」でブラウザの印刷機能を開き、PDFとして保存可能
   - 日本語フォントをブラウザ側で処理するため、追加のPDFライブラリやフォントファイルは不要

## PDF保存について

Ver.2.8ではサーバー側でPDFファイルを直接生成する方式ではなく、**A4印刷用HTML → ブラウザの「PDFに保存」**を採用しています。

理由は次の通りです。

- 日本語フォントの埋め込みトラブルが起こりにくい
- Vercelに特殊なPDF生成環境を追加しなくてよい
- PC・スマホの標準印刷/PDF機能を利用できる
- 印刷前に実際のレイアウトを確認できる

# 更新手順

## STEP 1: Supabase migration

GitHub更新より先に、Supabaseの **SQL Editor** で次を実行してください。

`supabase/migrations/013_invoice_documents.sql`

既存の請求・入金データは削除しません。

既存の請求レコードは税率0%として維持されます。必要なものだけ請求編集画面から税率を設定してください。

## STEP 2: GitHubへ上書き

`personal-crm-v2.8` フォルダの **中身** を、GitHubリポジトリ直下へ上書きしてください。

今回、新規ルートとして以下を追加しています。

- `app/invoices/[id]/page.tsx`

新規ファイルがGitHubへ漏れないよう、フォルダごとのアップロードを推奨します。

## STEP 3: Vercel

mainへ反映すると自動デプロイされます。

今回は以下の変更はありません。

- Google Cloud設定：変更なし
- OAuth Scope：変更なし
- Vercel環境変数：追加なし

# 初期設定

デプロイ後、まず **設定 → 請求書設定** を開いてください。

最低限、次を入力しておくことを推奨します。

- 発行者名 / 屋号
- 住所
- メールまたは電話
- 振込先
- 請求書番号の接頭辞
- 既定税率

適格請求書発行事業者の登録番号を持っている場合のみ登録番号を入力してください。

# 動作確認

1. 案件の「請求・入金」を開く
2. 請求予定を作成
3. 明細名・税率・請求先を確認
4. 「請求済」に変更
5. 請求書番号が自動採番されることを確認
6. 「請求書」ボタンを開く
7. 発行者、請求先、請求額、税額、振込先を確認
8. 「印刷 / PDF保存」からPDFとして保存

## 既存の請求済レコード

Ver.2.8以前に「請求済」になっていたレコードで請求書番号がない場合は、請求情報の編集画面を一度保存すると自動採番・スナップショット保存が行われます。
