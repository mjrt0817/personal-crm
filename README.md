# Personal CRM Ver.3.0

個人用SFA / CRM / 案件・タスク・スケジュール・Google Workspace・見積・請求管理ツール。

## Ver.3.0 のテーマ

見積 → 案件 → 実施 → 請求 → 入金まで一通りつながったため、今回は新機能を増やすよりも **日常操作の分かりやすさ** を優先してUIを再整理しています。

### 1. 案件詳細の横タブを廃止

Ver.1.7から使っていた横タブは、PCでは一覧性が低く、項目が増えるほど横移動が必要でした。

Ver.3.0では案件詳細を次の構成へ変更しています。

- PC: 左側の縦型「案件メニュー」 + 右側の詳細
- スマホ: 「表示する情報」のプルダウン + 詳細
- URLの `?tab=tasks` 等はそのまま互換利用可能
- 編集画面からタスク・リンク等の元の表示へ戻る動作も維持

案件メニュー:

- 概要
- 活動履歴
- タスク
- 予定
- 関連リンク
- Google Drive
- メモ

### 2. 見積・請求を「概要」へ統合

以前は案件を開くと、見積カード・請求カード・AIカード・詳細タブが縦に並んでいました。

Ver.3.0では、

- 案件の基本情報
- 見積
- 請求・入金
- AI案件レビュー

を **概要** の中へまとめています。

そのため案件を開いた直後は、次回予定・次回アクション・クイックリンクと案件メニューに集中できます。

### 3. 案件クイック操作を追加

案件ヘッダー直下に、日常的に使う操作をまとめました。

- ＋ 活動を記録
- ＋ タスク
- ＋ 予定
- ＋ 見積
- ＋ 請求予定

訪問後の活動記録や予定・タスク追加で、目的の場所を探す手間を減らします。

### 4. 左サイドバーを業務別に整理

PCのサイドバーを以下にグループ化しました。

- 日常業務
- 営業・売上
- 補助機能

AI参謀は「補助機能」に残しています。AI機能自体を後回しにしても入口を忘れない構成です。

## 更新方法

Ver.3.0ではDB変更はありません。

- Supabase SQL: 追加実行なし
- Google Cloud: 変更なし
- Vercel環境変数: 変更なし

ZIP内の `personal-crm-v3.0` フォルダの **中身をGitHubリポジトリ直下へ上書き**してください。

Vercelの自動デプロイ完了後、以下を確認してください。

1. 案件詳細を開く
2. PCで左側に「案件メニュー」が表示される
3. 「活動履歴」「タスク」「Google Drive」等がクリックで切り替わる
4. 見積・請求は「概要」内に表示される
5. 案件ヘッダー下のクイック操作から活動・タスク・予定を追加できる
6. スマホでは案件詳細の表示切替がプルダウンになる

## 既存機能

Ver.2.9.1までの以下の機能は維持しています。

- Google認証 / Supabase RLS
- 取引先・担当者
- 案件・活動・タスク・予定
- Google Calendar双方向連携
- Google Drive案件フォルダ連携
- Gmail案件連携
- 回答待ちフォロー
- 優先アクション
- 売上・見込管理
- 単価 × 回数案件
- 請求・入金管理
- 請求書発行 / PDF保存
- 見積書作成 / PDF保存
- 見積から案件化・請求への引継ぎ
- JSONバックアップ / CSV出力
- AI参謀（任意）
