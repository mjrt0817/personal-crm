# Webサイト構築 注文条件の標準案

注文書作成画面で選択・反映後、案件に合わせて編集するための標準案です。

## 検収条件

【確認対象】見積書・注文書および別途合意した仕様に記載するページ、掲載内容、機能を対象とし、別紙の納品・検収チェックリストで確認します。対象外の項目は理由を記録します。
【確認時期】公開前に掲載内容・デザイン・基本動作を確認し、公開後に本番環境で表示・リンク・フォーム通知等を再確認します。
【確認期間】注文者は、検収依頼と確認用URL・必要情報を受領後7営業日以内に確認結果を連絡します。期間内の確認が難しい場合は、期限までに申し出て延長期間を協議します。不具合は該当ページ・内容・確認環境をまとめて通知します。
【修正と完了】合意内容との相違・動作不良について必要な修正と再確認を行い、注文者がメール、LINEまたは検収書等で明示的に承認した時点で検収完了とします。公開や期間経過だけでは検収完了としません。

## 確認環境

PC：Google Chrome・Microsoft Edge／スマートフォン：iOS Safari・Android Chrome（確認時点の最新版。対象端末・OSは案件に合わせて合意）

## 修正・追加変更

合意した業務範囲・仕様との相違や制作に起因する動作不良は修正対象とします。承認後のデザイン変更、ページ追加、新機能、原稿差替え等の追加・変更依頼は、着手前に費用・納期への影響を協議して合意します。

## 検収後の不具合・保守

検収後に判明した合意内容との相違・不具合は、原因と契約内容を確認して対応します。更新・運用・保守や新たな追加変更は別契約・別途見積とします。検収完了だけを理由に契約不適合に関する責任を一律に免除するものではありません。

## 成果保証の範囲

検索順位、アクセス数、問い合わせ件数、売上等の成果は、別途明示的に合意した場合を除き保証対象としません。合意したSEO設定や計測機能の設定・動作は確認対象とします。
